This is a static demo. The comments, votes, and users on this page are hardcoded. Files you attach never leave your browser: the upload is simulated and the comment you post is kept in memory only, so it resets when the page reloads.

File attachments in the comment widget: two flows

Both columns use the comment widget's real markup and stylesheet. Attach a file from your computer in either column, then submit the comment to see how it is posted. Drag and drop works in Option B.

Option A: Paperclip in the editor toolbar

A paperclip sits next to the image button. Attached files appear as chips under the comment box, and posted comments show a compact list of files with a download action.
